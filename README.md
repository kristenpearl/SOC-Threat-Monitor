# SOC Threat Monitor

## Overview

SOC Threat Monitor is a Security Operations Center (SOC) platform designed to support cybersecurity monitoring, incident management, and threat detection activities.

The platform provides visibility into security events, alerts, and incident workflows while demonstrating key concepts used in modern Security Operations Centers.

## Features

- Threat Monitoring
- Alert Management
- Incident Tracking
- Risk Classification
- Security Reporting
- Security Dashboard
